# Alana Edwards Space Systems Engineer: Anomaly Detection

## Contents
- anomaly_detection.py: loads the data, makes the plots, computes the percentages,
  and runs the anomaly detection functions
- plots/: all plots for question 1
- answers.txt: answers to questions 2 through 4, plus assumptions and data notes
- percentages.csv: the question 2 results
- requirements.txt: Python packages needed

## How to run
1. Install the packages: pip install -r requirements.txt
2. Place the provided CSV files in a folder called "Support Files" next to the script.
3. Run: python anomaly_detection.py

The script saves the plots to plots/, saves percentages.csv, prints the percentages
and the anomaly report, and prints the total run time.
